## 按学习状态汇总

这张表使用本页顶部的 topic 属性筛选概念笔记。每篇只选一个状态标签：待整理、研读中、已理解。没有匹配笔记的状态暂不显示。

```dataview
TABLE WITHOUT ID learningState AS "学习状态", rows.file.link AS "概念笔记", length(rows) AS "篇数"
FROM "01-Concepts"
WHERE type = "concept" AND typeof(this.topic) = "string" AND topic = this.topic
FLATTEN file.etags AS learningTag
WHERE contains(list("#待整理", "#研读中", "#已理解"), learningTag)
SORT created DESC
GROUP BY replace(learningTag, "#", "") AS learningState
SORT choice(learningState = "待整理", 1, choice(learningState = "研读中", 2, 3)) ASC
```
